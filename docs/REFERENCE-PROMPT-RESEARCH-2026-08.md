## 样本信号

六本可稳定切出前 30 章的样本，每章约 2,332-2,813 字符，中位数约 2,405-2,811 字符。非空行中，42%-93% 长度不超过 25 字符；对话标记平均每章约 59-81 个。它们共同呈现短段、频繁动作与对话切换、单章聚焦一个关系或事件变化的形式。

这不是字数或段落的硬指标。样本集中于都市、校园、多女主和关系张力题材，不能将其题材、伦理关系、口头禅、人物类型或桥段迁移到其他小说。

可迁移机制：

1. 开场先交代当前场景中的目标、异常或压力，再按需补充背景。读者应迅速知道谁在做什么、为什么现在必须做。
2. 一章不是“发生了一段对话”，而是至少改变一个故事状态：目标、风险、关系、信息、资源、认知或位置。
3. 冲突由“人物想要什么，什么在阻止他，角色怎么选择，要付什么代价”构成。误会和反派不能只为拖延服务。
4. 爽点、反转、暧昧和胜利都先建立对象、障碍与期待，再由主角行动兑现。兑现后留下合理的新问题，不把悬念写成空泛的“到底会怎样”。
5. 对话必须推进信息、关系、博弈或行动之一。角色语气由身份、目的和情绪决定，而不是所有人都用同一套俏皮话。
6. 高压段优先动作、感受和短句；缓和段才安排环境、人物和心理。背景介绍、总结性评论和解释不应截断正在升级的冲突。

## 规范交叉验证

| 主题 | 规范库结论 | 提示词转译 |
| --- | --- | --- |
| 开篇 | 清楚、贴合卖点、快速切入、有具体冲突和早期回报 | 续写开头接住前章压力或给出即时目标，不用泛泛回顾开场 |
| 冲突 | 冲突、行动、结局组成故事；冲突需服务人物与主线 | 要求目标、阻力、选择、代价，拒绝角色降智和纯误会拖延 |
| 爽点与期待 | 先强化需求与阻碍，再兑现；不能持续全高潮 | 先铺垫再兑现，兑现后产生新债或行动压力，保留张弛 |
| 节奏 | 快慢、密疏、张弛、紧缓分层控制；紧张段减少慢元素 | 场景级规则：紧时动作/感受，缓时再用环境/心理；不设机械字数配额 |
| 对话 | 对话应有目的并改变关系或信息 | 每次对话至少推动一个故事变量，区分说话者动机与口吻 |
| 铺垫与悬念 | 信息需先出现，后续回收要改变理解或行动 | 不凭空翻转；关键兑现前建立可回看的因果线索 |

## 提示词决策

Writer 采用“内化检查，直接写作”的方式：先在心里完成本章节拍，不把提纲或自评输出给作者。它包含状态变化、冲突四要素、铺垫兑现、对话功能、节奏切换和去空泛化要求。

Reviewer 不以样本文风作为评分标准，只检查是否存在可定位的事实冲突、无状态变化、无因果的冲突、未铺垫的关键兑现、无功能对话和破坏节奏的解释性文字。题材、长度和是否采用强钩子均不是单独的错误条件。

## 使用边界

- 项目内的角色、世界书、锁定笔记、章节事实和用户的当次要求始终优先。
- 该合同用于提高可读性和连载节奏，不能强迫古言、悬疑、严肃文学或慢节奏作品写成都市情感爽文。
- 参考书仅作抽象机制分析；不得要求模型复写、续写、模仿或混用其中的剧情、角色、台词和专有设定。
